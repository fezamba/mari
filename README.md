# 💗 Projeto: Site de 2 Anos

Este projeto é um site comemorativo feito para celebrar meus 2 anos de relacionamento.
Ele foi criado como presente com cores rosa e branco, e uma galeria de fotos.

## ✨ Tecnologias Utilizadas

* HTML
* CSS
* JavaScript

## 📱 Funcionalidades

* Layout **mobile-first**, responsivo para desktop
* Carta personalizada
* Galeria de fotos embaralhadas automaticamente
* Modal para visualizar fotos em destaque

## ▶️ Como Executar

1. Baixe ou clone o projeto
2. Abra o arquivo **`index.html`** no navegador
3. Já está funcionando

## 📁 Estrutura do Projeto

```
index.html      -> Página principal
style.css       -> Estilos do site
script.js       -> Lógica
img/            -> Pasta com as fotos usadas
```
