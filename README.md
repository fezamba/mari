# 💗 Projeto: Site de 2 Anos

Este projeto é um site comemorativo feito para celebrar meus 2 anos de relacionamento.

## ✨ Tecnologias Utilizadas

* HTML
* CSS
* JavaScript

## 📱 Funcionalidades

* Layout **mobile-first**, responsivo para desktop
* Carta personalizada
* Galeria de fotos
* Modal para visualizar fotos em destaque
* Botão no final da página para tocar uma música

## ▶️ Como Executar

1. Baixe ou clone o projeto
2. Coloque suas fotos dentro da pasta **`img/`**
3. Adicione sua música na pasta **`music/`** com o nome `music.mp3`
4. Abra o arquivo **`index.html`** no navegador
5. O site já estará funcionando

## 📁 Estrutura do Projeto

```
index.html      -> Página principal
style.css       -> Estilos do site
script.js       -> Lógica (galeria, modal, música)
img/            -> Pasta com as fotos usadas
music/          -> Pasta com a música
```
